# RealityKit feature suite

| Platform | App | Device requirement | Purpose |
| --- | --- | --- | --- |
| iOS | [LiDAR capture app](ios/README.md) | **Physical iOS 18+ LiDAR iPhone required** | Scan spaces and objects, export GLB assets, and attach visual evidence to an Ansight session. |

The scan flow is a manual physical-device test. Its Ansight workspace includes
a scan-artifact trigger; it has no automated test definition yet.

Build, device requirements, and Ansight workspace registration are described
in the [iOS app guide](ios/README.md).
